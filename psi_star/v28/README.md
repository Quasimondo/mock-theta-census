# Scripts of addendum v28 (what kind of object is f*?)

Python 3 with mpmath. Run from inside this folder: `python3 x1_kind.py > run_log.txt` (about 5 seconds).

- `x1_kind.py [a b c] [N]`
  - a: the double-sum identities (N1)–(N5) and their versions for index 0, exact to order N = 300.
  - b: growth of ψ₁*, f₁* along rays arg x = ε against the exponents of Theorem 19; Ramanujan's ψ₁, f₁ for comparison.
  - c: the q-difference equations in z for F, F̌ and the bilateral sum.
- `run_log.txt`.
