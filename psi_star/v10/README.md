# Scripts for psi-star-addendum-v10

Needs Python 3 with mpmath only.

    python3 exact3.py           # five points on horocycles: psi1* minus the two state-integral terms against the Borel sum (15 s)
    python3 exact3_sectors.py   # nine more points in other directions of t (30 s)

q2_series_v3.json: perturbative series of psi1*, psi0* at q -> 1 from the v3 scripts (151 terms, 120 digits).
run_log.txt is the output of both commands.
